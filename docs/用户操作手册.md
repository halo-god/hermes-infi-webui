## 1. 产品简介

Hermes 信使是一个全栈 AI 协作平台：你可以通过 Web 界面与 AI 助手对话、上传并管理文件、组建团队群聊、设定定时任务、接入知识库。

**核心能力一览：**

| 能力 | 说明 |
|---|---|
| 对话 | 与 AI 助手多轮对话，支持 Markdown / 表格 / 代码高亮 / 图片 |
| 文件 | 会话内上传、预览、编辑、版本历史、Diff 对比 |
| 附件 | 消息可携带文件（docx / xlsx / pptx / pdf / 图片等），AI 直接读取 |
| 定时任务 | 让 AI 在指定时刻自动执行任务并回传结果 |
| 团队 / 群聊 | 组建团队、多成员群聊、AI 助手入群 |
| 搜索 | 全局搜索会话与消息（⌘K） |

## 2. 快速开始

### 2.1 登录

在浏览器打开平台地址，使用管理员分配的账号（邮箱 + 密码）登录。登录后进入首页。

![首页](manual-images/01-首页.png)

**首页布局：**

- **左侧栏**：导航（首页 / 所有会话 / 搜索 / 定时任务 / 文件管理 / 终端）、团队列表、会话列表（会话 / 群聊两个页签）、底部（后台管理 / 反馈 / 个人设置）
- **主区域**：欢迎语与输入框。输入问题后回车即可开始对话
- **顶栏**：折叠侧栏（⌘\）、全局搜索（⌘K）、反馈中心、通知、帮助中心、切换氣質（主题）、调整 Tweaks

### 2.2 开始第一次对话

在底部输入框输入问题（如"帮我写一份周报模板"），按 `Enter` 发送。AI 助手会流式回复：

![会话对话](manual-images/02-会话对话.png)

- 回复支持 **Markdown**（标题、列表、加粗）、**表格**、**代码高亮**、**Mermaid 流程图**
- 消息下方可：**表情**、**复制**、**重新生成**、**分享**
- AI 的思考过程与执行步骤可点击展开查看

## 3. 会话与对话

### 3.1 创建与管理会话

- **新建会话**：点击侧栏"所有会话"旁的 **+**（或 ⌘N）
- **重命名 / 置顶 / 删除**：鼠标悬停会话条目，点击右键菜单操作
- **搜索会话**：顶栏 ⌘K 打开搜索面板

![搜索面板](manual-images/09-搜索面板.png)

### 3.2 发送消息与附件

点击输入框左侧的 **附件** 按钮，弹出附件菜单：

![附件菜单](manual-images/03-附件菜单.png)

- **上传本地文件**：从本机选择文件（支持 docx / xlsx / pptx / pdf / txt / csv / 图片 / zip 等）
- **引用文件管理文件**：引用"文件管理"中已上传的文件
- **引用知识库**：引用团队知识库条目（需团队已配置知识库）

> **上传体验**：office / pdf 等大文件上传后**立即返回**（无需等待转换），文件以"转换中…"状态出现在工作区，后台解析完成后自动可预览。AI 读取附件时直接读取原始文件，质量完整无截断。

### 3.3 消息操作

| 操作 | 说明 |
|---|---|
| 表情 | 给消息添加表情反馈 |
| 复制 | 复制消息内容 |
| 重新生成 | 让 AI 重新回答本条问题 |
| 分享 | 生成分享链接 |
| ⎇ 分叉 | 从该消息开始创建新会话分支 |

### 3.4 停止生成 / 失败重试

- AI 回复过程中，输入框发送按钮变为 **中断** 按钮，点击可停止生成
- 生成失败时消息会显示**失败原因**（网络 / 超时等）与"重新生成"按钮，可直接重试；输入框中的草稿在失败时会保留，便于重发

### 3.5 分享会话

把会话分享给**没有账号的人**查看（例如给客户看一份调研结论）：

1. 侧栏悬停目标会话 → 右键菜单 → **分享** → 生成分享链接（已复制到剪贴板）

![分享菜单](manual-images/14-分享菜单.png)

2. 把链接发给对方，对方无需登录即可**只读查看**（最多显示最近 50 条消息）
3. 需要收回时：同一菜单变为 **取消分享** → 点击后链接**立即失效**

![取消分享](manual-images/15-取消分享菜单.png)

> **分享范围与权限**：
> - 分享出去的内容**实时跟随**会话——分享后产生的新消息对方也能看到；取消分享即彻底关闭
> - 匿名访客只能看到消息正文与附件文件名，**看不到**团队知识库名称、成员 ID、内部引用等元数据
> - **个人会话**：创建者可分享 / 取消分享
> - **群聊 / 团队会话**：仅会话创建者或**团队所有者 / 管理员**可分享（普通成员无法把团队频道公之于众），取消分享同理

## 4. 文件与工作区

### 4.1 打开工作区

会话顶栏点击 **工作区 (N)** 打开文件面板（N 为文件数）。即使没有文件也可打开面板并直接上传：

![工作区面板-空态](manual-images/04-工作区面板-空态.png)

### 4.2 文件预览与操作

![工作区面板-文件预览](manual-images/05-工作区面板-文件预览.png)

| 操作 | 说明 |
|---|---|
| 上传 | 面板内直接上传文件到当前会话 |
| 编辑 | 纯文本类文件（md / txt / json 等）可在线编辑保存 |
| 下载 | 下载原始文件 |
| 版本历史 | 查看历史版本、预览旧版本、**Diff 对比**、一键恢复 |
| 全屏 | 预览区全屏展示 |
| 删除 | 鼠标悬停文件节点，点击 **✕**（需二次确认） |
| 重试 | 解析失败的文件（红色"解析失败"标记）可点击 **↻** 重新解析 |

**文件类型预览支持：**

- **Markdown**：渲染标题 / 列表 / 表格 / 代码 / Mermaid 流程图
- **Office（docx / xlsx / pptx / doc / xls / ppt / odt / ods / odp）**：统一转为 **PDF 保真预览**（版式、字体、图表完整保留，服务器内置 LibreOffice 转换；soffice 不可用时新格式降级为简化渲染、旧格式提示转存）
- **CSV**：表格化预览
- **代码 / JSON**：语法高亮
- **图片 / PDF**：内联预览

> **转换中 / 解析失败**：上传后文件显示"转换中…"（脉冲徽标），后台解析完成后自动刷新；解析失败显示"解析失败"，可重试或删除后重新上传。

### 4.3 会话文件标签

消息上会显示**本轮关联的文件标签**（仅当前轮次产生的文件，不是全部工作区文件），点击标签可直接在工作区打开该文件。

### 4.4 跨会话引用文件

**同一个人的会话之间可以互相引用文件**：

- 在会话 A 中上传的文件，在会话 B 发消息时可通过附件菜单 **引用**（附件选择器会列出你所有会话的文件）
- 被引用的文件会写入当前会话的工作区，AI 可直接读取
- 安全边界：只能引用**你自己**会话的文件；**其他成员 / 其他团队**会话的文件不可引用

> **提示**：希望长期复用的资料建议放到 **文件管理**（相当于个人文件库），任何会话都可引用；会话工作区里的文件偏"会话私有"。

## 6. 定时任务

侧栏点击 **定时任务**：

![定时任务](manual-images/07-定时任务.png)

### 6.1 新建任务

点击 **新建任务**，配置：

| 字段 | 说明 |
|---|---|
| 任务名称 | 便于识别的名称 |
| 执行内容（Prompt） | 告诉 AI 要做什么 |
| 执行助手 | 选择执行任务的助手（Profile） |
| 执行时间 | Cron 表达式或选择固定时刻 |

### 6.2 任务生命周期

- 任务到点后自动执行，结果写入**任务专属会话**（侧栏可见 ⏰ 前缀会话）
- 执行完成 / 失败会通过**通知**提醒
- 任务执行中产生的**文件会自动同步到该会话的工作区**，可在会话工作区面板中查看、预览
- **删除任务专属会话不影响任务本身**：下次触发时会**自动重建一个全新的任务会话**继续写入结果（历史消息不保留，任务逻辑不受影响）

> **示例**：每天 08:30 生成 AI 日报并推送到微信 —— 新建任务，Prompt 写"使用 AIHOT 技能生成日报并发送给我"，执行时间填 `30 8 * * *`。

## 7. 群聊与团队

### 7.1 团队

侧栏中部为**团队列表**。点击 **+** 可创建团队。团队用于组织成员、知识库、权限。

**团队知识库**（团队页 → 知识库 页签）：

![知识库预览](manual-images/16-知识库预览.png)

- **上传文件**：docx / xlsx / pptx / pdf / md / csv 等均可入库，上传后自动建立向量索引（"已索引 N 块"），供团队成员在任意会话中**引用知识库**做检索增强回答
- **文件夹**：用文件夹组织条目；删除文件夹会**递归删除**其中所有条目
- **预览与编辑**：点击条目直接内嵌预览（office 走 PDF 保真预览、md 走渲染预览），可改名 / 移动 / 版本历史 / 重试解析
- **权限**：上传、删除需对应团队权限（由团队所有者 / 管理员配置）；**任何会话引用知识库时，系统会校验引用者属于该团队**——不是团队成员拿不到内容

**项目**（团队页 → 项目 页签）：

- 项目内可创建**项目文档**（上传文件，同样支持 PDF 预览）与任务看板
- 项目文档可在会话中引用；删除项目时其文档与对象存储会一并清理

### 7.2 圆桌讨论（多 AI 并行作答）

在群聊中 **@所有AI**（或创建群聊时选择多个 AI 助手），即可触发**圆桌模式**：多位 AI 助手并行作答，最后由主助手综合各方观点输出汇总。

![圆桌讨论](manual-images/13-圆桌讨论.png)

**圆桌消息结构：**

| 区域 | 说明 |
|---|---|
| 顶部徽标 | 会话头显示 **圆桌 · N 位并行** |
| 各助手卡片 | 每位助手独立作答（显示助手名 + 状态：作答中 / 完成 / 失败） |
| 综合汇总 | 主助手 **"综合各方观点"** 输出最终结论 |

**每张助手卡片提供：**

- **采纳**：把该助手的回答作为正式回复采纳
- **追问**：单独向该助手追问细节
- **转给我**：把问题转给其他助手 / 真人成员

> **典型用途**：让多个不同人格的助手（如 情感大师 + 投资研究助手 + 通用助手）从各自视角回答同一问题，得到多角度结论。



侧栏下方切换 **会话 / 群聊** 页签：

![侧栏群聊](manual-images/10-侧栏群聊.png)

- 点击 **创建群聊** 新建群聊（选择成员与 AI 助手）
- 群聊中 **@ 成员** 或 **@ 所有 AI** 触发 AI 回复
- 群聊支持：成员管理、频道模式（@ 提及 / 全员自动回复）、群聊文件

## 10. 实操场景

以下为高频真实使用场景的完整操作路径，可直接照做。

### 10.1 会议纪要整理

**场景**：会议录音转写文本或随手记录的笔记，让 AI 整理成结构化纪要。

**步骤：**

1. 打开一个会话（或新建会话）
2. 点击输入框左侧 **附件** → **上传本地文件**，选择会议记录文件（txt / md / docx 均可）
3. 输入整理指令，例如：

```
请把这份会议记录整理成会议纪要，要求：
1. 按议题归纳（结论先行）
2. 列出行动项表格（事项 / 负责人 / 截止时间）
3. 标注待确认问题
```

4. 发送后 AI 会先读取附件原始内容，再输出结构化纪要（含 Markdown 表格）

**效果示例：**

- AI 回复包含：**会议结论**、**行动项表格**、**遗留问题**
- 点消息下方 **复制** 可直接粘贴到工作群 / 文档
- 后续可继续追问："把行动项导出为 CSV 文件" —— AI 会生成文件到工作区

> **技巧**：指令中明确输出格式（结论先行 / 表格 / 分点），AI 输出质量显著提升。

### 10.2 行业调研报告输出

**场景**：让 AI 输出一份完整的行业调研报告（多 Agent 并行调研 + 交叉验证 + 文件交付）。

**步骤：**

1. 新建会话，输入调研需求，例如：

```
调研中国机器人行业的现状与未来发展前景
```

2. AI 会：
   - 加载行业调研技能，**并行派发多个子代理**（宏观 / 财务 / 产业链等维度）
   - 自己独立拉取行情、搜索关键数据做**交叉验证**
   - 汇总各子代理产出，整合成完整报告
3. 报告以消息形式交付（含核心结论表），**同时落盘到会话工作区**

![调研报告交付](manual-images/12-调研报告交付.png)

4. 点击顶栏 **工作区 (N)** 打开面板，可查看/下载完整报告与各子代理底稿：

![工作区文件预览](manual-images/05-工作区面板-文件预览.png)

> **要点**：
> - 报告文件自动出现在工作区（子代理的调研底稿也在）
> - 消息中的 **文件标签** 可直接打开对应文件
> - 可继续追问："把报告结论整理成 PPT 大纲" 或 "按我的投资筛选标准跑一遍初筛"

### 10.3 文档快速分析（上传 PPT / Excel）

**场景**：拿到一份 PPT / Excel 汇报材料，快速提炼核心内容。

**步骤：**

1. 上传文件（PPT 大文件上传后立即返回，后台解析）
2. 输入："总结这个 PPT 的结构和要点"

AI 会直接读取原始文件（docx / xlsx 原生读取；PPT 由后台 Docling 升级为高质量文本后注入），输出结构化总结 —— 标题层级、每页要点、表格数据一目了然。

### 10.4 定时自动化（AI 日报）

**场景**：每天早上自动生成行业日报并推送。

**步骤：**

1. 侧栏进入 **定时任务** → **新建任务**
2. 配置：
   - 执行内容：`使用 AIHOT 技能生成今日 AI 行业日报并发送给我`
   - 执行时间：`30 8 * * *`（每天 08:30）
3. 保存后任务自动生效

**效果**：每天 08:30 AI 自动执行 → 日报生成到任务会话工作区 → 推送通知。执行记录与产出文件在 ⏰ 前缀的任务会话中可查。
### 10.5 圆桌多视角讨论（群聊 @所有AI）

**场景**：一个需要多角度回答的问题（方案评审、观点辩论、多领域交叉分析），让多个助手并行作答后综合。

**步骤：**

1. 侧栏 **群聊** 页签 → **创建群聊**，成员中添加 **多个 AI 助手**（不同人格 / 专长的 Profile）
2. 在群聊输入框发送消息，**@所有AI** 后附上问题，例如：

```
@所有AI 请分别从【技术架构】【成本预算】【团队能力】三个角度，
评估我们是否应该自建 AI 平台而非采购 SaaS 方案。
```

3. 各助手**并行作答**（圆桌卡片逐一出结果）：
   - 每位助手独立给出其视角的答案
   - 作答完成后主助手**综合各方观点**输出汇总结论
4. 对某个助手的回答可：**采纳**（作为正式回复）/ **追问**（深入讨论）/ **转给我**（切换人选）

> **要点**：
> - 圆桌的并行作答由后端 WS 通道实时回传，各卡片状态（作答中 / 完成 / 失败）实时可见
> - 单一助手作答失败不影响其他助手（失败卡片会标注，可"转给我"重试）
> - 需要单一助手回答时，**@指定助手** 即可（只触发该助手，不进入圆桌）

## 12. 常见问题

### Q1：上传的 office 文件为什么显示"转换中…"？

大文件（docx / xlsx / pptx / doc / xls / ppt / pdf 等）上传后先在后台转换（office 文件由 LibreOffice 转为 PDF 预览，秒级到数秒），转换完成自动变为可预览。解析期间不影响你继续对话；AI 读取该文件时直接读取原始文件（docx / xlsx 原生读取），不受转换状态影响。若长时间停留在"转换中"，可刷新页面；显示"解析失败"可点击 **↻ 重试** 或删除后重新上传。

### Q2：为什么 AI 看不到我上传的附件？

1. 确认消息发送时附件已出现在输入框上方（未发送前可点 × 移除）
2. 上传后**立即发送**时，大文件可能仍在"转换中"——系统会自动等待其就绪（最长约 2 分半，多个大文件排队转换时更久），超时或失败会提示"附件转换未完成"
3. 引用文件的范围：当前会话的文件、**你自己其他会话的文件**、"文件管理"的文件均可引用；**他人 / 其他团队**会话的文件会被拒绝（这是安全边界，不是故障）
4. 若附件一直卡在"转换中…"超过数分钟，可点击文件行上的 **↻ 重试** 强制重新解析

### Q3：编辑文件后下载，为什么还是旧内容？

纯文本类文件（md / txt 等）编辑后即同步保存；office / pdf 等二进制文件**不支持在线编辑**（编辑按钮不显示）。如需修改请下载后编辑再重新上传。

### Q4：定时任务没执行 / 没收到结果？

1. 检查任务是否启用（enabled）
2. 检查执行时间（Cron 表达式）是否正确
3. 执行结果在任务专属会话（⏰ 前缀）中查看，失败会显示原因
4. 任务产物文件在工作区面板中查看
5. **账号被停用**（管理员操作）后，其所有定时任务不再触发——恢复启用后自动恢复
6. 任务被禁用 / 删除后，已排队但未执行的那一次也不会运行（不会"删了还跑"）

### Q5：会话删除后还能找回吗？

删除会话为**永久删除**（消息与工作区文件一并清理），请谨慎操作。重要内容建议先下载文件备份。

**例外**：**定时任务专属会话**（⏰ 前缀）删除后，任务下次触发时会**自动重建全新会话**继续执行——任务本身不受影响，只是历史消息不保留。

### Q6：.doc / .xls / .ppt 旧格式文件为什么打不开？

旧版 Office 二进制格式需要服务器安装 LibreOffice 才能解析。**标准部署（Docker）已内置 LibreOffice**，doc / xls / ppt 与 OpenDocument（odt / ods / odp）可直接上传、预览、交 AI 读取；仅当服务器未安装 LibreOffice 时（如裸机开发环境）会提示"暂不支持该格式，请转存为 docx / xlsx / pptx"。**将文件另存为新格式后重新上传即可**。

### Q7：分享出去的会话怎么收回？

侧栏悬停该会话 → 右键菜单 → **取消分享**。取消后分享链接**立即失效**（对方刷新即 404）。注意：分享内容实时跟随会话，取消前对方能看到分享后新增的消息。

### Q8：为什么我不能删除 / 分享某个群聊？

- **群聊 / 团队会话的删除与分享**仅限**会话创建者**或**团队所有者 / 管理员**——普通成员无法删除全队聊天记录，也无法把团队频道公开分享出去
- 个人会话不受此限制（创建者可自由删除 / 分享）
- 成员被移出团队后，其对团队群聊 / 项目群的访问会**立即失效**（不会残留）
